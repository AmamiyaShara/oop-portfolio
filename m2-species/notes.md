# M2 物種報告：風囊生物

## 一句話介紹

風囊生物是一種生活在「餘留城市」屋頂的植物型生物：它以日光維持生長，利用自然風與殘存通風設備移動，把風扇框、百葉風口和通風管當成可以附著、成熟與繁殖的機械棲地。

**牠憑什麼在這個世界活下來？** 牠不依賴完整電網，也不把電當食物；牠靠日光進行植物型代謝，再借用城市中偶爾出現的氣流完成移動、附著與散播。

## 世界背景

故事發生在人類消失約 30–40 年後的「餘留城市」。大型電網和大部分設備已經停止，只剩極少數老化的太陽能板、排風機與通風設施，在有日照或自然風時間歇運作。城市因此不是全面有電，而是由死區、偶爾啟動的衰退節點，以及少數仍有氣流的屋頂構成。

風囊生物把這些原本服務人類的設備視為環境的一部分。設備提供的不是食物，而是附著表面、局部氣流、震動和散播路徑。這些機械棲地會逐漸故障，所以牠必須在棲地完全消失以前不斷遷移與繁殖。

## 物種設定書

### 1. 型態：牠長什麼樣、多大？

風囊生物的本體是一顆橢圓種囊，表面有縱向紋理；成熟後長出三片半透明膜翼、三條細長鉤索，以及一根會發芽、形成花苞並開花的細莖。鉤索末端可以勾住風扇外框、百葉風口或通風管的邊緣，膜翼則會隨風張開。

設定上，本體約 2–3 公分長，膜翼完全展開約 8–12 公分，鉤索可延伸約 10–20 公分。這個尺寸足以被屋頂氣流帶動，也能讓同一個大型通風設備同時容納多個個體。程式中的比例是視覺化草模，不是精密的生物量測模型。

**設計依據：** 膜翼與飄散方式參考蒲公英種子的被動飛行；研究顯示蒲公英冠毛能增加阻力並形成穩定氣流結構，讓種子在不主動耗能的情況下停留空中。鉤索是為城市金屬框架而延伸出的虛構構造。

### 2. 代謝：牠吃什麼、能量從哪裡來？

風囊生物是植物型生物，主要能量來自日光。附著並完成成熟後，它才會長出綠色組織，在白天累積生長能量；光線不足時停止生長並進入枯萎狀態。風力不是牠的食物，電力也不是牠的代謝來源。

作品把陽光簡化成一個可調整的環境值，用來控制發芽、花苞、開花與枯萎。現實中的光合作用還需要水、二氧化碳與礦物質；本設定暫時假設種囊能從雨水、灰塵及屋頂裂縫中的有機物取得其他物質。

**設計依據：** 光合作用會利用光能，把二氧化碳與水轉成可供生物使用的有機物；因此「有光生長、缺光停止」有生物學基礎，但程式中的速度與形變是為了讓觀眾看見生命狀態而壓縮的表現。

### 3. 繁衍：牠怎麼複製自己？

個體附著後先經過三個完整夜晚的成熟期，再開始七個完整日夜的成體生活。第七天結束後才進入繁殖期；風力足夠時，成熟個體會釋放兩顆較小的後代種囊。後代帶著一根初生鉤索，被風帶往新的風扇或風口，找到空位後開始和母體相同的生命流程。

每個後代的初始體型是親代當輪體型的 78%。這使族群能增加，但每一代不會無限制維持原尺寸；缺少附著空間的種囊會飄離屋頂，無法在畫面中的棲地定居。

**設計依據：** 散播方式參考風力傳播種子。蒲公英研究支持「輕量構造＋氣流」能延長種子的滯空與散播距離；一次釋放兩顆、78% 體型與七天週期則是本作品為了呈現族群變化所做的創作規則。

### 4. 行為：牠的天性、怕什麼、追什麼？

風囊生物沒有像動物一樣主動追逐目標，而是用簡單的環境反應形成行為：

1. 有足夠日照時，裂縫中的種囊出土並生長。
2. 第一根鉤索形成後，風力足夠才會離地飄散。
3. 飄散時優先尋找仍有空間的風扇框、百葉風口或通風管。
4. 勾住後會隨風擺動與旋轉；風越強，離固定點越遠，膜翼也張得越開。
5. 成熟前只長鉤索與膜翼，不會提前發芽、開花或枯萎。
6. 成熟後對光線產生反應：有光發芽、形成花苞並開花，缺光則枯萎。
7. 繁殖期等待足夠風力，再把後代送往其他棲地。

**設計依據：** 這些行為採用類似 Braitenberg Vehicles 的簡單「刺激—反應」關係：光控制生長狀態，風控制移動、張翼與散播。人工光研究也顯示光線能改變生物的活動時間、生理與繁殖，因此光同時作為能源和環境訊號是合理的延伸；本作品目前使用的是日光，而不是讓生物依賴仍會亮的城市燈具。

### 5. 威脅：什麼會殺死牠？

風囊生物面對四種主要威脅：

1. **長期缺光：** 無法維持生長，成熟組織會持續枯萎。
2. **風力不足：** 種囊無法離開裂縫，成熟個體也不能散播後代。
3. **沒有附著空位：** 找不到安全框架的種囊會被吹離屋頂。
4. **機械棲地衰退：** 風扇、線路和結構逐年故障，使可用的氣流與落腳點愈來愈少。

每個個體本身也有壽命限制：一輪生命結束後會縮小 10%，最多完成七輪；第七輪凋謝並落回裂縫後正式死亡。這個「七輪壽命」是創作規則，用來讓個體有老化與終點，而不是永遠循環。

**設計依據：** NREL 指出太陽能模組可設計為運作 30–40 年，但輸出會逐年退化；這只支持少量老化能源節點仍可能存在，不代表風扇、控制器和線路一定能同樣持久。因此作品把仍運作的設備設定成罕見、間歇且正在消失的棲地。

## 完整生命循環

### A. 裂縫與飄散

1. 第一代從屋頂縫隙中的種囊開始，而不是從完整土壤長出。
2. 日照足夠後出土，接著長出第一根鉤索。
3. 當風力高於起飛門檻，種囊被自然風帶離裂縫。
4. 系統會沿四種棲地的框架尋找可用位置：兩台排風機、一個百葉風口和一個通風管。
5. 落腳點依框架周長、成熟後的展翅範圍與其他個體距離動態分配，不限制每台設備只能掛固定數量。

### B. 三夜成熟期

1. 勾住棲地後進入成熟期。
2. 第一夜完成後延伸其餘鉤索。
3. 第二夜完成後長出膜翼。
4. 第三夜完整結束後成為成體。
5. 三夜尚未結束以前完全不會發芽、開花或枯萎。

### C. 七天成體期

1. 成熟後才開始計算七個完整日夜。
2. 有光時依序發芽、長葉、形成花苞並開花。
3. 不論處於第幾天，只要缺光就停止生長並枯萎；光線恢復後可再次生長。
4. 第七天完成以前不能繁殖。

### D. 繁殖、凋謝與下一輪

1. 滿七天後進入繁殖期，等待足夠風力。
2. 符合條件時釋放兩個較小後代；後代具有和母體相同的成熟、開花、枯萎、繁殖與死亡能力。
3. 母體釋放後完全凋謝、膜翼收縮、鉤索鬆脫並落回屋頂裂縫。
4. 回到裂縫算完成一輪；下一輪重新從種囊開始，體型縮小 10%。
5. 每個個體最多進行七輪，第七輪結束後不再重生。

## 原型目前具備的功能

### 環境模擬

- 屋頂場景包含太陽能板、兩台排風機、百葉風口、通風管、女兒牆、裂縫與遠方建築。
- 可手動調整風力與陽光強度。
- 風力可切換自動循環，並影響風扇轉速、個體飄移距離、旋轉速度、膜翼展開與繁殖散播。
- 日照可切換自動循環；背景明暗會隨日照變化，生命階段以完整日夜轉換計時。
- 重新開始按鈕可把環境和族群重設到第一顆種囊。

### 個體與族群觀察

- 可在全景與個體近看視角間切換。
- 可選擇族群中的不同個體，查看牠所在的棲地。
- 畫面顯示目前循環、體型、成熟夜數或成體日齡，以及族群數量。
- 右鍵拖曳可旋轉視角；鏡頭會避開屋頂地板、女兒牆和設備實體，減少穿入場景。
- 多個個體可以掛在同一設備，只要成熟後的身體與膜翼仍有足夠間距。

### 階段檢視

階段選單可以暫停即時模擬，直接查看：裂縫種子、出土、第一根鉤索、飄散、附著、三個成熟階段、發芽、花苞、開花、夜間枯萎、繁殖散播、完全凋謝、掉回裂縫與生命結束。也能指定第 1–7 輪及成體第 1–7 天；返回即時模擬後，原本的族群進度會繼續。

### 程式實作

- 生命狀態、環境數值、繁殖、棲地分配與鏡頭運算由 Rust 撰寫並編譯成 WebAssembly。
- p5.js 負責在瀏覽器中建立 WebGL 畫布並繪製 Rust 傳來的幾何命令。
- 網頁可以直接載入已編譯的 WASM；觀看作品不需要先安裝 Rust。
- 專案包含生命週期與瀏覽器測試，檢查三夜成熟、七天成體期、七輪壽命、後代可繁殖、動態棲地容量、階段預覽、鏡頭界線和手機版介面。

## 設定中需要誠實說明的部分

有研究支持的部分包括：太陽能模組能長期但逐漸退化、植物利用光能生長、光會影響生物狀態，以及輕量種子可利用風被動散播。

屬於創作推演的部分包括：鉤索構造、三夜成熟、七天成體生活、每次兩個後代、後代為親代的 78%、每輪縮小 10%、七輪後死亡，以及設備能在無人維修 30–40 年後仍偶爾運作。這些規則不是宣稱現實中已存在的物種，而是把「逐漸消失的機械棲地」轉成可觀察、可互動的生命模型。
