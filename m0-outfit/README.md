# M0 裝備

## 執行方式

用瀏覽器開啟 `index.html`，畫面中央會顯示一個持續呼吸縮放的圓形。

正常執行畫面保存在 `preview.png`。

## 讓 AI 出錯實驗

實驗時把 p5.js 的 `circle()` 函式誤寫成不存在的 `circl()`。瀏覽器無法畫出圓形，開發者工具顯示 `ReferenceError: circl is not defined`。錯誤畫面保存在本資料夾的 `ai-error.png`，最終程式已改回正確的 `circle()`。
